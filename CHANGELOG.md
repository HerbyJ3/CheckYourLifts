# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-23

### Added
- Initial release of CheckYourLifts web application
- Interactive body map visualization with front and back views
- 40+ exercises across all major muscle groups
- Real-time muscle group highlighting
- Exercise search and filtering by category
- Workout builder interface
- Selected exercises panel with workout summary
- Responsive design for all screen sizes
- Modern gradient UI with smooth animations
- Category filters (Upper, Lower, Core, Back)
- Clear all exercises functionality
- Visual muscle group indicators with color coding

### Technical
- React 18.2.0 with hooks
- Vite 5.0 build system
- Tailwind CSS 3.4 for styling
- SVG-based body map component
- Component-based architecture
- ESLint configuration

### Documentation
- Comprehensive README with setup instructions
- SETUP.md for installation guidance
- CONTRIBUTING.md for contributor guidelines
- ROADMAP.md for future development plans
- Development Guide integration
- VSCode workspace configuration
